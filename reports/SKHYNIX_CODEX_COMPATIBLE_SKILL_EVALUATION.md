# 실행 환경이 호환되는 검증 스킬 평가

**Native005는 학습 검증 요건을 충족하지 못해 평가 전에 중단했다. 새 평가 실행은 0/18회이며 해결률과 조건별 차이는 미측정이다.**

실행기·Python 호환성 문제는 해결했지만, 두 독립 학습 문제가 절차 검증과 공식 해결을 모두 만족하지 못했다.
사전에 선언한 대로 스킬 승격이나 전달 검사를 완화하거나 관찰 전용 평가로 대체하지 않았다.

| 학습 문제 | 공식 해결 | 선언한 공개 검사 | 실제 절차 승인 |
| --- | --- | --- | --- |
| 19637 | 성공 | 새 회귀 검사는 통과했지만 전체 명령은 기존 AST 오류 2개로 실패 | 거부 |
| 19783 | 실패 | 수정 전 assertion 실패 후 4개 통과·2개 건너뜀 | 거부 |

19637의 새 테스트를 제외한 원본 코드에서도 같은 공개 명령을 별도 깨끗한 환경에서 실행했다.
원본은 41개 통과·5개 건너뜀·2개 예상 실패·2개 예외였으며, `test_evaluate_false`와 `test_issue_17811`에서
같은 Python AST 오류가 재현됐다. 따라서 이 두 오류는 이번 패치가 새로 만든 실패가 아니다.
그러나 기존 v1은 선언한 전체 명령의 성공을 요구하므로, 범위를 좁힌 검사의 성공으로 대신하지 않았다.
[원본 공개 검사](../artifacts/skhynix_v1/codex_005/public-training-baseline-diagnostic.json)에 기록했다.

19783은 공개 검사를 통과했지만 공식 grader에서 해결 실패였다. 공개 검사 성공만으로
정확성을 승인하지 않았다. 기존 `attest_procedure()`가 두 기록을 모두 거부했고 실제 승격 시도도
실패했다. **승격 스킬 0개, 평가 은행 없음, 평가 계획·풀이·채점 없음**이다.
[학습 승인 판정](../artifacts/skhynix_v1/codex_005/training-gate-decision.json)과
[미실행 비교 상태](../artifacts/skhynix_v1/codex_005/experiment-status.json)를 보존했다. 이를 해결률 0%로 표현하지 않는다.

## 환경과 표본 선정

기존 DEV·heldout·smoke 및 native002·003·004를 제외한 SymPy 후보는 56개였다.
공개 식별자·제목·기준 커밋·시점을 살펴봤고, 공개 `bin/test` 원문 해시를 검사했다.
제목은 확인했지만 선정 알고리즘에는 사용하지 않았다. 같은 실행기 해시의 후보 14개를
digest로 고정한 실제 이미지에서 검사했다.

최초 학습 후보 19495는 Python 3.9.21이어서 기존 경로가 요구하는 3.9.20과 달랐다.
새 풀이·채점·실행 계획·manifest 생성이 모두 0회일 때 실제 Python 조건을 추가했다.
14개 중 나머지 13개가 같은 실행기와 Python 3.9.20 조건을 만족했다.
최초 계약·후보와 [사전 변경 기록](../artifacts/skhynix_v1/codex_005/pre-execution-supersession.json)을 보존했다.
초기 `git show` 진단은 무관한 미수신 Git 객체에 영향을 받아, 최종 선정에는 정확한 `cat-file blob` 결과를 사용했다.

번호 순으로 첫 번째 가능한 학습 두 문제와 그 뒤의 첫 여섯 평가 문제를 골랐다.
최종 학습은 19637·19783, 평가는 19954·20154·20428·20438·20801·21379다.
Git 조상·시점 검사 13개(학습→평가 12개, 학습→학습 1개)가 통과했다.
난도 검증이나 무작위 표본으로 해석하지 않는다.

학습 시작 전 여덟 이미지의 공개 기본 검사는 각각 22개 또는 23개가 통과했고,
전후 깨끗한 checkout과 동일한 실행기·Python을 확인했다. 별도 합성 조회 검사는 사전 선언만 했으며,
스킬 승격이 실패해 실행하지 않았다. 이를 실제 스킬 주입 실적으로 세지 않는다.

## 실행·검증 범위

같은 요청 모델 `gpt-6-astra`와 부모에게서 상속한 reasoning 설정, `fork_turns="none"`의 독립 세션
두 개를 사용했다. 각 학습은 빈 메모리로 한 번만 수행했고, 공식 채점도 각각 한 번이었다.
세션당 120회 도구 요청·첫 요청부터 1,200초·최대 3회 기억 주입·12,000 bytes를 유지했다.
별도 모델 API 호출은 0회이며 Codex 자체 토큰·비용과 내부 날짜별 snapshot은 측정하지 못했다.
호스트 도구 제한은 지침·중계 기록·자기 확인으로 관리했고, 모든 호스트 활동의 부재를 OS 수준에서 증명한 실험은 아니다.

관련 검사 **324개**와 기존 동결 파일 **651개** 검사가 통과했다. 독립 감사는
**4,303개 통과, 실패 0개**, 상태는 `PASS_GATED_BEFORE_EVALUATION`이다.
이는 중단 기준과 증거가 올바르다는 뜻이며, 해결률 비교가 완료됐다는 뜻이 아니다.
[감사](../artifacts/skhynix_v1/codex_005/audit.json)와 [공개 증거 목록](../artifacts/skhynix_v1/codex_005/public-artifact-manifest.json)을 보존했다.
공개 수집물에는 제출 패치 원문·전체 도구 대화·개인 경험 DB·비공개 채점 원문을 넣지 않았다.
