C의 네 세션 모두 실제 메모리 전달이 0회였다. 따라서 이 비교는 현재 검색 정책을 포함한 전체 구성의 관측 결과이며, 지식을 전달했을 때의 효과를 측정한 결과는 아니다. 검색 옵션의 개발 질의 개선은 재현했지만, 이번 다른 문제들에 대한 지식 전달로 이어지지는 않았다. 이번 실험에서도 문제 해결률 상승은 확인하지 못했다. 이 네 문제는 기준선부터 모두 해결해, 관측된 기준선 대비 추가 해결률의 여지가 없었다.

[Native008](SKHYNIX_CODEX_FAILURE_RECOVERY_EVALUATION.md)은 알려진 두 실패 문제에서 문제 해결 0/4 대 0/4, 공식 필수 테스트 실행 통과 0/6 대 1/6이었다. 이번에는 그 문제들과 겹치지 않는 네 문제에 동일한 공개 진단 지식을 적용한다.

이 네 문제는 확인한 저장소의 Native002–007 등록과 겹치지 않는, 기존 공개 실행 환경 검증 후보의 잔여 목록이다. 알려진 개발 문제 21596은 제외했다. 전역적으로 처음 보는 문제이거나 무작위 표본이라는 주장은 하지 않는다. 원본 DEV·heldout 분할도 바꾸지 않았다.

A는 빈 메모리, C는 SKHYNIX 컨트롤러와 동결한 공개 진단 지식을 사용한다. 출처는 Native007의 20428·20438 실패 A 세션 및 독립 공개 진단이며, 분석 문장·제목·출처 명세는 Native008과 같다. 전체 기록에는 이번 전이 실험의 시나리오를 표시하므로 Native008과 바이트까지 같지는 않다. Gate A는 실패 에피소드 2개, Gate B 승격 0, KG 관계 0이다. 자동으로 검증된 성공 스킬의 전이 실험은 아니다.

검색은 명시적으로 `DIAGNOSTIC_LESSON_CONTENT`를 선택했다. 후보 선별과 순위에는 제목·분석 본문을 쓰고, 실제 전달에는 출처와 해시를 포함한 전체 기록을 유지한다. 기준 0.05·범위 검사·예산은 유지했다. 이 변경은 Native008 C의 공개 질의가 메타데이터 때문에 9/219=0.04110으로 탈락한 진단을 바탕으로 했으며, 새 네 문제의 실행 결과를 보고 고른 변경은 아니다. 제목과 분석 본문만 비교하면 같은 질의는 9/163=0.05521이다. 특정 개발 질의의 검색 개선을 새 문제 해결률 상승으로 해석하지 않는다.

모델은 매번 `gpt-6-astra`, `fork_turns=none`으로 요청했다. 공통 지시문과 문제·도구·한도는 같다. 세션당 broker 요청 120회·1,200초·메모리 최대 3회/12,000바이트이며, 같은 문제의 독립 A/C 세션을 최대 두 개 병행한다. 추가 지시·결과를 본 재시도·교체·메모리 업데이트·실패 제외는 없다. 실제 조회가 보류되면 그 세션도 분모에 남긴다. B는 준비만 하고 실행·채점하지 않는다.

등록 경로 검사 168개, 검색 수정 및 기존 경로 검사 155개를 통과했다. 공개 캐시와 8개 조상·시간 관계를 재검증했고, 네 실행 소스에 동결한 파일 337개를 각각 복사했다. 새 솔버 실행 전에 사전 전달 검사 8개와 모든 실제 셀 요청 0회를 확인했다.


최종 무결성 검사는 **13,136 PASS**, 공개 증거는 **168개·1,849,536바이트**다. 이전 Native007 208개·Native008 165개 공개 증거와 원본 진단 보호 대상 32개 파일의 바이트를 다시 검증했다. 여덟 세션 모두 정상 제출했고, 실제 세션당 최대 요청 수는 29회였다. 별도 모델 API 호출은 0이며 Codex 토큰·비용은 계측하지 않았다.

모델·새 문맥·호스트 접근 제한은 요청한 설정과 솔버의 자기 확인에 근거한다. 저장한 지시문 해시는 기록된 지시문의 일치를 검증하며, 실제 백엔드 입력이나 모델을 독립적으로 증명하지는 않는다. 병행 수 검사는 broker 사용 시작부터 제출까지의 구간을 대상으로 한다.

최종 집계 도우미가 단위 테스트 파일도 실행 소스 복사 목록에 있다고 가정해 첫 검사가 중단됐다. 결과 집계 파일 생성 전에 도우미만 수정했고, 실행 소스는 동결 목록으로, 두 단위 테스트 파일은 봉인된 검증 영수증과 저장소 바이트로 확인했다. 원본 도우미와 수정 기록을 공개 증거에 포함했다. 모델·테스트·공식 채점은 다시 실행하지 않았으며 기존 제출물과 채점 결과는 바꾸지 않았다.
