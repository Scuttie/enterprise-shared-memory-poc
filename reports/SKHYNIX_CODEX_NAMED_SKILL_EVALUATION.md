# 이름을 고정한 회귀 검증 스킬 평가

상태: **native006은 실제 실행기의 정상 실패 출력을 검증기가 잘못 거부하는 결함을 확인해 조기 중단했다. 학습 공식 채점은 4회 중 2회 해결, 승인된 학습 증거·승격 스킬은 0개다. 평가 실행은 0/18회로 해결률은 미측정이다.**

중단 사유는 `EARLY_ABORT_OBSERVER_DEFECT`다. 실제 RED 출력은 `0 passed, 1 failed`였으나 검증기는
`1 failed`만 허용하고 0개의 통과 표기까지 거부했다. 19637의 두 번째 시도는 새 함수 하나, 직접 assertion 실패,
변경 없는 구현, 동일 테스트·명령의 GREEN을 실제로 기록했지만 이 출력 파싱 결함으로 거부됐다.
해당 관찰을 성공한 학습 증거로 소급 변경하지 않는다. 19637의 첫 시도는 실패한 선언 호출까지 세는 엄격한 바인딩
검사에서 거부됐고, 19783의 두 시도는 공식 해결에 실패했다. 공식 해결 판정과 절차 검증 결과는 구분한다.
문제당 최대 3회 한도를 소진한 중단은 아니다. 19637의 세 번째 시도는 환경만 준비했고 모델·도구 실행은 0회다.
기존 소스·결과를 보존한 뒤 별도 실험에서 관찰기 오류를 수정할 계획이다. 평가 6문제는 계속 미실행 상태다.

종료 감사는 **11,868개 통과·실패 0개**다. [공개 증거 116개](../artifacts/skhynix_v1/codex_006/public-artifact-manifest.json)를
보존했으며, [관찰기 결함 진단](../artifacts/skhynix_v1/codex_006/training-19637-a2-verifier-diagnostic.json)과
[19783 공개 동작 진단](../artifacts/skhynix_v1/codex_006/training-19783-public-diagnostic.json)을 포함한다.
19783은 세 제출 모두 오른쪽 항등원만 처리하고 문서가 보장하는 왼쪽 항등원 동작은 놓쳤다.
공식 결과는 각각 신규 검사 1/2·기존 검사 9/9 통과이고 인프라 실패는 없었다.
공개 누락과 숨겨진 실패 assertion이 정확히 같은지는 확인하지 않았다.

후속 작업은 별도 [다중 파일 절차 평가](SKHYNIX_CODEX_MULTISOURCE_SKILL_EVALUATION.md)에서 진행한다.

절차 관련 265개와 주변 파이프라인 239개, 총 504개 검사가 통과했다. 기존 저장소 동결 검사도 651개 파일에서 통과했다.
8개 환경 모두 Python 3.9.20과 동일한 공개 실행기를 사용하며, 기존 basic 검사 22개 또는 23개 및
이름으로 선택한 `test_structure` 정확히 1개가 통과했다. 모든 사전 검사 전후 checkout은 깨끗하다.
실행 계약 SHA256은 `2ee5e9cc316deb96caace00799e42b3cd105c290ae0bc6bae9a32383f8d882e9`,
v2 선언은 `70437a961574d980293c8cbce99fdc871d788606da590513a5c71cae76868c94`이다.

native005는 학습 단계의 검증 요건을 만족하지 못해 평가 전에 중단했다. 한 학습 문제는 공식 해결에
성공했지만 원래 공개 모듈의 Python AST 오류 때문에 전체 검사 GREEN을 얻지 못했고, 다른 문제는
공개 검사 GREEN을 얻었으나 공식 해결에 실패했다. 이 결과를 수정하거나 스킬 승격 성공으로 바꾸지 않는다.

새 절차는 첫 수정 전에 회귀 테스트 함수 이름을 고정하고, 공개 실행기의 `-k`로 해당 테스트만 실행한다.
부분 문자열 선택의 모호성을 막기 위해 선언한 새 함수 하나만 선택되는지 확인한다. 기존 공개 테스트는
보존하고 새 함수 하나에 필요한 assertion들을 넣는다. 실제 assertion 실패와 동일 테스트·명령의 정확히
1개 통과가 필요하며, 오류·건너뜀·테스트 미실행은 성공으로 인정하지 않는다.

공식 전체 채점 성공과 서로 다른 학습 문제 두 개의 검증 증거가 필요하다는 Gate A/B 조건은 유지한다.
새 procedure ID·template hash·증거 버전을 사용하며 기존 v1 기록은 보존한다. 새 스킬의 검증 범위는
선택한 회귀 테스트의 RED→GREEN 절차이며, 전체 공개 테스트가 통과했다는 주장을 하지 않는다.

학습 19637·19783은 **005에서 이미 관찰한 학습 문제**로 명시해 재사용할 계획이다. 평가 6문제는
19954·20154·20428·20438·20801·21379를 유지한다. 이 평가 대상에는 아직 풀이·공식 채점을 실행하지
않았으며, 학습 결과를 보고 평가 문제를 교체하지 않는다.

학습에서는 문제당 최대 3개의 새 세션으로 실제 검증 자료 수집을 시도하고, 각 문제에서 처음으로
절차 검증과 공식 채점을 모두 통과한 세션만 은행에 넣을 계획이다. 모든 실패 시도도 기록한다.
평가는 문제×조건마다 한 번만 실행하며 결과에 따른 재시도나 기억 조정은 하지 않는다.
실행 전에 이 조건과 소스·질의·예산·은행을 단계별로 고정한다.
