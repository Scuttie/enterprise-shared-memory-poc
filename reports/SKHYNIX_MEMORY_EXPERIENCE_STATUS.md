## 경험 한 건에 담기는 내용

경험 한 건은 하위 작업과 공개 도구 실행 이력을 특정 시점에 저장한 체크포인트다. 실제 읽기·수정·명령 실행, 관측된 테스트 결과와 출처가 연결된다. 한 문제에서 여러 체크포인트를 저장하므로 이력은 서로 겹칠 수 있다. **607건은 독립적인 교훈 607개나 성공 사례 607개를 의미하지 않는다.**

| 체크포인트 | 해결 문제에서 | 미해결 문제에서 | 보류 문제에서 | 합계 |
| --- | ---: | ---: | ---: | ---: |
| 공개 테스트 결과 관측 | 115 | 135 | 23 | 273 |
| 하위 작업 완료 | 166 | 145 | 15 | 326 |
| 종료 시점 미완료 작업 | 3 | 4 | 1 | 8 |
| 합계 | 284 | 284 | 39 | **607** |

테스트 관측 273건은 공개 테스트 실패 RED 103건과 통과 GREEN 170건이다. 이는 현재 인식 규칙에 맞는 테스트 관측만 세며 전체 테스트 실행 수와 같지 않다. 공개 테스트 GREEN은 해당 명령의 통과를 뜻하고 공식 문제 해결을 보증하지 않는다. 하위 작업 완료 기록도 공식 정답 판정과 다르다.

미해결·채점 보류 문제도 그때까지 수행한 탐색·수정·공개 테스트 이력을 보존한다. 공식 grader의 숨겨진 테스트나 정답을 경험에 넣지 않는다. 실패 원인을 자동으로 정확히 진단하거나 일반화된 교훈으로 만든 것으로 해석하면 안 된다.
