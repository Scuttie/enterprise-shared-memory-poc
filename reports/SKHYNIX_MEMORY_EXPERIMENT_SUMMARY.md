**OFF와 ON의 차이는 정확히 구분해야 한다.** 실제 코드에서 두 조건은 현재 작업 문맥·하위 작업 그래프(L0)와 새 세션 인계를 공유한다. OFF는 장기 메모리 검색·주입을 하지 않고, ON은 동결된 L1·L2·L3를 현재 하위 작업에 맞게 검색·주입한다. 따라서 현재 비교는 **공통 L0·실행 환경 위에서 장기 메모리를 추가한 효과**다.
