## 기존 기록 승계와 실행 상태

기존 실행은 18번째 `pytest-dev__pytest-5205`의 제출 후 공식 보고서가 `no_tests_collected`로 결과를 확정하지 못해 멈췄다. 기존 **18개 제출·실행 감사 통과 기록 중 공식 결과가 확정된 것은 17개**이며, 그 결과는 해결 9개·미해결 8개다. 나머지 1개를 해결 성공이나 실패로 재분류하지 않았다. 공개 풀이 기록은 채점 결과와 별개로 수집한다.

[승계 근거](../artifacts/skhynix_v1/architecture_scale_001/source-adoption-002.json)는 원래 설정·셀·실행 감사·제출 패치·공식 결과/불확실성 보고서의 정확한 해시를 보존한다. 기존 18문제를 다시 풀거나 채점하지 않는다. 첫 실행 대상은 아직 풀지 않은 scikit-learn 3840·7760, Sphinx 7234·7268, SymPy 11232·11384의 6개다. 이후 96개, 다시 120개를 추가하여 총 240개의 고유 문제 경험을 모은다. 새 풀이 예정은 **222개**다.

실행 이미지 800개의 공개 레지스트리 정보와 digest를 고정했다. 최초 조회에서 3건이 요청 제한 429를 받아 그 조회만 다시 수행했고, 모두 확인했다. 문제 선정이나 모델 풀이의 재시도는 없었다. 실제 각 문제 환경의 동작 여부는 해당 문제 준비 단계에서 검사한다.

코드 검증은 관련 단위·회귀 테스트 **622개 통과** 및 개발 기준선의 등록 범위를 수정한 실행 제어기 추가 검사 **16개 통과**다. 후자의 16개는 앞의 622개와 중복되는 검사이므로 합산하지 않는다. 기존 실행 코드는 별도 snapshot으로 보존했고 새 런타임 391개 파일과 공식 loader 경로를 고정·검증했다. 제어기 v2는 모델 실행 전에 개발 기준선의 등록 범위를 바로잡은 것으로, 풀이 결과를 본 뒤 바꾼 설정이 아니다.

[구현 검사와 시작 검증 근거](../artifacts/skhynix_v1/architecture_scale_001/implementation-validation-v2.json)에는 테스트 원본·새 제어기·런타임 import 101개 경로 검증·개발 기준선 60개 등록·원래 경험 승계의 참조를 연결했다.

본 평가의 `resolved`는 공식 채점의 FAIL_TO_PASS와 PASS_TO_PASS 요건을 모두 만족한 결과만 뜻한다. 공개 테스트 성공, 모델의 완료 선언, 학습 수집 기록 수를 본 평가 해결률로 사용하지 않는다. 평가가 덜 끝났거나 채점이 불확실하면 전체 500개 해결률 및 최종 차이를 확정하지 않는다.
